# Original images (full quality)

Master copies of website photos, kept at full quality. They are not served on
the site; the compressed copies the site uses live in `app/assets/`.

**To edit a website photo, always start from the master here (or the original
download), never from the compressed copy in `app/assets/`.** Every re-save of a
compressed file makes it a little softer. Save the edited master here, then
export the site copy from it once.
